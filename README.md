# Student Details Website

A simple and user-friendly Student Details website created using **HTML, CSS, and JavaScript**.

This project allows users to enter details of up to **5 students**. The student information is stored in a JavaScript array and displayed on the webpage in separate block-shaped cards.

---

## 📌 About the Project

The Student Details Website is a basic web development project created for academic and practical purposes.

The user can enter:

- Student Name
- Roll Number
- Course

After clicking the **Add Student** button, the information is stored in a JavaScript array and displayed on the webpage as an individual student card.

The website allows a maximum of **5 students** to be added.

---

## ✨ Features

- Enter student name
- Enter roll number
- Enter course
- Store student details in a JavaScript array
- Display student details dynamically
- Display each student in a separate block/card
- Maximum limit of 5 students
- Empty field validation
- Student counter
- Responsive design
- Simple and clean user interface
